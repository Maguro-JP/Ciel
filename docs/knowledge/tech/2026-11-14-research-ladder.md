# 調べ物を 5 段で残し、段を節の中身から数える

- 日付: 2026-11-14
- 語: 調べ物, 知識, アルゴリズム, 技術, 実装, knowledge, compound, 段

## 情報
- compound-engineering-plugin は、作業の最後に学びを docs/solutions/ に書き、次の計画がそれを読む。考え方は「1 つの仕事が次の仕事を楽にする」（https://github.com/EveryInc/compound-engineering-plugin 、MIT、2026-11-14）
- Claudeception は、残す物を「調べないと分からなかった」「次の作業で使える」「使う場面が言える」「動かして確かめた」で絞り、文書を読めば済む物と確かめていない物を残さない（https://github.com/blader/Claudeception 、MIT、2026-11-14）
- 公開されているスキルを検索した範囲では、学びを文書に残す物はあったが、アルゴリズムと再利用できるコードまで進んだかを機械で数える物は見つからなかった

## 知識
調べ物は、残す場所と形が決まっていないと情報のまま消える。形を 情報・知識・アルゴリズム・技術・実装 の 5 つの節に固定すると、どこで止まっているかが見える。
「できた」と自分で書く欄は当てにならないので、段は節に中身があるかで数え、技術の節に書いたファイルが実在するかを見る。
前の段が空のまま先に進んだ物は数えない。手順の無いコードは、次の人が直せないからである。
使えない場合: 1 回きりの事実（版の番号、綴り）。残すと探す物が増えるだけなので、残さない理由を 1 行書いて通す。

## アルゴリズム
入力は 1 件の Markdown。出力は段（0〜5）と注意の列。
1. `## 情報` などの 5 つの見出しで本文を分け、説明のコメントと空行を除いた行を各節の中身とする
2. 上の節から順に、中身があれば段を 1 つ進め、空の節で止める
3. 情報に URL も「動かして確かめた」も無ければ注意
4. 技術の節のバッククォートの中からファイルらしい物を拾い、根からの相対で実在を見る。無ければ注意。テストの行が無ければ注意
5. 段が 1 以下で、ファイル名の日付から 7 日たっていれば注意
Stop フックの判定: この 3 ターン以内の調べ物の呼び出しのうち、最後の docs/knowledge/ への書き込みより後ろの物を数え、1 つ以上あり、このターンで編集かコミットがあり、残さない理由の行が無ければ止める。
端の場合: フックの差し戻しと裏の処理の通知は、新しいターンに数えない。費用は記録の全行の読み 1 回。

## 技術
- 場所: `.claude/skills/research-to-tech/scripts/knowledge.py` の `rung_of` と `read_entry`
- 場所: `.claude/skills/research-to-tech/hooks/research_gate.py`（Stop）、`.claude/skills/research-to-tech/hooks/research_nudge.py`（PostToolUse）
- テスト: `.claude/skills/research-to-tech/scripts/test_knowledge.py`

## 実装
- このセッションで調べた 4 件（README の節の順、検査のツール、Actions の通知、この件）を、この形で docs/knowledge/tech/ に残した
- `knowledge.py --check` の出力: `知識: 全 4 件 / 実装 4 / 技術 0 / アルゴリズム 0 / 知識 0 / 情報のまま 0（注意 0）`
