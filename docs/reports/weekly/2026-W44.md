## 教訓の収穫（リポジトリ A と C から Ciel へ）

| 教訓 | 一般的な理由 |
|---|---|
| マージ前のテストが、変えた所のテストを流していなかった | テストの台本が一部のディレクトリだけを流す形は、どのリポジトリでも起きる |
| パイプの後ろの終了コードを、処理の成功と読んだ | `| tail` のあとの `$?` は tail のもの。裏で処理を回すスキル全部に効く |
| テストとコミットを 1 つのコマンドに並べ、落ちたまま push した | solo-pr-flow と auto-dev の手順に直接効く |
| 開いた PR にサイクルごとに push して、そのたびに CI を回した | auto-dev の PR=daily の理由そのもの。Actions の枠は全リポジトリで共通 |
